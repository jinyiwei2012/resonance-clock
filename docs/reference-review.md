# 参考资料核查摘要

本项目参考了若干旧版 Mod 效果说明，以帮助界定“状态回溯”“周期性回退”“昼夜推进/局部加速”和“延迟复活”等设计方向。

这些页面属于社区资料而非本项目的运行时证据；没有据此复制源代码，也不将其描述为对 Minecraft 1.20.1、Forge 47.4.5 或本 Mod 的兼容性承诺。

## 使用原则

- 旧效果仅作为设计灵感和待验证边界来源。
- 库存、世界状态、第三方资源和外部 Mod 交互不会因资料描述而被假定可安全恢复。
- 后续时间控制、复活和外部 Mod 适配必须分别研究、实现和测试。

原始链接清单、原始需求和参考图片属于本地资料，不随仓库分发。
