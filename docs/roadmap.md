# 后续阶段摘要

后续工作不是首版功能承诺，进入每一阶段前都需要重新确认规则、兼容边界和测试方案。

1. **时之紊乱与净化（0.2.0 已实现）**：固定快照、在线周期、死亡保留、物品/管理员/成功扭结净化。
2. **进化形态与配置**：I–XII 环与月相环的手动切换、外观细化和经确认的能力倍率。
3. **分层时间控制**：将昼夜、实体行为和方块/方块实体 tick 视为不同问题；先做隔离实验，不承诺通用机器加速或全局时停。
4. **伤害/防护与终结技研究**：先核对精确伤害来源、多人状态和专服性能，再考虑实现。
5. **独立扩展**：范围加速、死亡复活和外部 Mod 适配分别独立决策，不作为首版隐含内容。
6. **Apollon 精准适配**：现有证据不足以确定安全的箭矢拦截接口；0.2.0 不实现全箭拦截，后续取得可靠 API 与行为证据后再独立设计。

任何阶段若无法证明安全性、清理逻辑或性能，应保持关闭或退回已验证的较小范围。
