# 首版设计摘要

Resonance Clock 的首版目标是一个独立的 Forge + Curios 遗物 Mod：装备遗物后提供投影式钟环和翼的外观、可选飞行，以及一次受服务端控制的状态回溯。

## 已实现范围

- Curios `charm` 槽位遗物
- I–XII 钟环和简化投影翼渲染层
- 默认关闭的飞行授权
- 时光扭结：记录状态、等待、校验安全位置后恢复允许状态
- 服务端配置、中文和英文文本

## 时光扭结边界

会处理位置、维度、生命、饥饿/饱和度、氧气、燃烧、伤害吸收和允许管理的原版效果。不会恢复背包、装备、经验、方块、容器、掉落物或第三方资源。目标不安全、维度无效或传送校验失败时会取消本次恢复而非部分恢复。

## 明确限制

飞行使用原版 `mayfly`，原版状态无法安全表达多来源所有权，因此它是管理员选择启用的独占模式，不应与其他飞行授权并用。

完整设计原稿和原始需求仅保留在本地资料中，不随此仓库分发。
